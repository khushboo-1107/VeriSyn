# VeriSyn

AI-powered digital security platform for detecting deepfakes and protecting digital files.

## Live Demo

https://veri-syn-5xrr.vercel.app/

## Overview

VeriSyn is a digital security platform designed to help users identify manipulated media and protect sensitive digital files.

The platform combines two major security modules:

- **Deepfake Shield** — detects whether images or videos are real or AI-generated/manipulated.
- **CrypTure** — provides secure file protection and encryption.

## Features

- AI-powered deepfake detection
- Image and video analysis
- Secure file upload
- File encryption and protection
- User profile and file management
- Security-focused user interface
